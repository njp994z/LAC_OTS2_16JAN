To ensure the **Secondary Controller Faceplate** for the sulfur flow controller (1530-F-2602) behaves consistently with the **Primary Controller Faceplate** on the home screen, the implementation should follow the same visual style, interaction patterns, layout structure, and state handling logic. Below is precise, structured guidance you can provide directly to your development agent or use as acceptance criteria during code review.

### 1. Layout and Visual Consistency Requirements

Both faceplates must share identical structural and stylistic elements:

- **Header / Title Block**
  - Tag number: Large, bold (e.g. "1530-F-2602")
  - Description: Smaller text below (e.g. "Sulfur Flow Controller")
  - Background: Same gradient or solid color as primary (currently dark navy/gray)

- **Main PV / SP / OUT Display Area**
  - Three horizontal blocks (or stacked on narrow screens):
    1. Controller Output % (blue background, cyan text) – e.g. "46.5%"
    2. Process Variable (PV) value (yellow/orange background, black text) – e.g. "87.4 GPM"
    3. Setpoint (SP) value (yellow background, black text) – e.g. "100 GPM" (should be editable via arrows when in AUTO/MAN)
  - All three blocks should have identical:
    - Font family, size, weight
    - Padding and border-radius
    - Shadow / elevation
    - Color scheme (match exact hex codes from primary faceplate)

- **Bar Graphs / Deviation Indicators**
  - Left bar: Controller output (blue fill, 0–100%)
  - Right bar: Deviation or scaled PV vs SP (yellow/orange fill)
  - Center numeric deviation display (e.g. "77.5" in white box)
  - Use the same bar height, width ratio, and animation easing as the primary faceplate

- **Mode Buttons (ROUT, RCAS, AUTO, MAN, BYPASS)**
  - Same grid layout (2–3 columns)
  - Identical button sizes, colors, and hover/active states
  - Green for AUTO, gray for others (match primary exactly)
  - Lock icon / Modelock button in same position and style

- **Bottom Status / Area Strip**
  - Area label: "Drying / Acid"
  - Status indicators: PV OK, OUT OK (green diamonds or circles)
  - Trend icon, alarm bell, etc. – same placement and icons

- **Close (×) Button**
  - Same size, position (top-right), and hover effect

### 2. Interaction and Behavior Parity

- **Up/Down Arrows on SP**
  - Must be enabled when controller is in **AUTO** or **MAN** mode (same as primary)
  - Increment/decrement step size should match primary (typically 1% or 1 GPM – confirm exact value from primary)
  - Real-time update to SP value and immediate recalculation of deviation bar
  - If in CAS/ROUT mode, arrows should be disabled or hidden (match primary logic)

- **Mode Switching**
  - Clicking AUTO/MAN should immediately update:
    - Button highlighting
    - Enable/disable SP arrows
    - Change deviation bar behavior if needed
  - ROUT/RCAS should toggle remote setpoint tracking (if implemented)

- **Real-time PV Updates**
  - PV value (87.4 GPM in screenshot) must update smoothly when static simulation re-runs or when sulfur hydraulics solver returns new flow
  - Use the same animation/framerate as primary faceplate updates

- **Deviation Calculation & Coloring**
  - Deviation = SP – PV (or PV – SP – confirm direction from primary)
  - Bar fill color should shift to red/yellow/green based on deviation magnitude (match primary thresholds)
